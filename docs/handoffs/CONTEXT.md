# Handoff context router

Start with [current-state.md](current-state.md). It selects the active artifact and records the latest known review boundary. Confirm Git status and later user instructions before resuming work.

| Artifact | When to read |
| --- | --- |
| [Current state](current-state.md) | Resume work, identify current spec/plan, check pending review |
| [2026-09-04 brainstorming handoff](2026-09-04-v4-brainstorming.md) | Historical rationale and source-review findings preceding the replacement spec; its continuation instructions are superseded |

The dated brainstorming handoff is retained as project history. The current state and spec contain the decisions required to proceed; read the older handoff only for its historical rationale.

Dated handoffs are Layer 4 working history, not permanent project instructions. Add a row for a new substantial handoff and update current state. Do not assume the newest filename is approved or load all handoffs at session start.
